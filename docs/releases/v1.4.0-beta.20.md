# D2R Audio Mod v1.4.0-beta.20

This prerelease pairs with **D2RHub 0.9.111**. Update Hub first, then install the processor from Mod Management → Downloads & updates.

- Add `hub-compatibility` with product, executable version, required Hub version and processing contract. Hub-managed calls require matching `D2RHUB_VERSION` and `D2RHUB_PROCESSING_CONTRACT`; missing, older or newer incompatible identities are rejected before operations touch files. Old Hub calls using `--events` are also rejected.
- Room-tools r32 opens pause at 10ms, then queues exit, native submission and controller close at 50ms in child order. This replaces r31's 60ms submission without controller close.
- Double-Esc remains r3; audio telemetry v7 and audio recipe r3 are unchanged. Regenerate existing Mods and restart the game to load r32.
- Standalone GUI and ordinary non-event CLI remain available. Event-mode integrations must supply the matching Hub identity.

Validation covers Rust formatting, strict Clippy, unit tests, CLI handshake and incompatible-call rejection, plus release executable identity and artifact hashes. Timer order is not server acknowledgement; actual repeated room transitions remain subject to in-game verification.

中文：本版与 D2RHub 0.9.111 配套，新增双向互认，不匹配时禁止加工。局内创建/加入恢复在确认后 50ms 顺序退出、提交、关闭控制器。旧成品需重新加工并重启游戏；双击 Esc 与音频协议保持不变。
